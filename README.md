## My Contribution

My contribution focuses on DNA sequence input, validation, synthetic genome generation, and motif-match representation.

### Files Implemented

- `Fasta.java` — Loads and saves DNA sequences using FASTA format.
- `Dna.java` — Provides DNA sequence validation and utility operations.
- `GenomeGenerator.java` — Generates synthetic DNA sequences for testing.
- `MotifHit.java` — Represents information about detected motif matches.

### Sample Input

The `sample/` directory contains a sample FASTA file used to test DNA input handling.

### Project Goal

These modules support the DNA Sequence Analysis Tool by preparing DNA sequences and representing search results for the application's matching algorithms.
